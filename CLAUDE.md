# CLAUDE.md

## Comments

Never leave comments in this repo. No inline `//`, no block `/* */`, no JSX
`{/* */}`, no JSDoc, no TODO notes. Write code that reads clearly on its own
instead.

This applies to every file type: `.ts`, `.tsx`, `.css.ts`, config files.

If something needs explaining, put it in the commit message or the response to
the user — not in the source.
